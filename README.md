# Farnor Dental Park — نسخه ۳ آزمایشی

## اجرا
در پوشه farnor-v3 اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس http://localhost:8000 را باز کنید.

## صفحات جدید
- `/dashboard.html` — پنل مدیریت پزشکان، درخواست‌ها، طرح درمان و تنظیمات
- `/booking-demo.html` — فرم درخواست مشاوره با انتخاب اختیاری پزشک
- `/doctors-demo.html` — فهرست پزشکان ثبت‌شده
- `/patient-demo.html` — نمونه پنل بیمار

## هشدار بسیار مهم
این یک نمونه تعاملی **بدون بک‌اند و احراز هویت** است. داده‌ها در localStorage مرورگر ذخیره می‌شوند؛ به‌هیچ‌وجه اطلاعات واقعی بیماران، پزشکان، تماس‌ها یا درمان‌ها را وارد نکنید. اطلاعات نمونه برای آموزش و بررسی UX هستند و بین دستگاه‌ها همگام نمی‌شوند. این نسخه برای استفاده عملیاتی یا انتشار عمومی پنل‌ها مناسب نیست.

## پیش‌نیاز نسخه عملیاتی
- بک‌اند امن و دیتابیس جدا برای داده پزشکی
- احراز هویت، RBAC، لاگ ممیزی، بکاپ، رمزنگاری و کنترل دسترسی هر بیمار
- گردش کار تأیید پزشک و پذیرش، برنامه زمان‌بندی و جلوگیری از رزرو تکراری
- اتصال مجاز Instagram و APIهای مورد نیاز، تأیید محتوا توسط متخصص
- بررسی الزامات قانونی حفاظت از اطلاعات سلامت در ایران
- شماره تماس، آدرس، پزشکان، تصویرها و دامنه واقعی باید تأیید شوند
